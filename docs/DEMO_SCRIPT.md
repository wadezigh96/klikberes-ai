# 3–5 minute KaneCLI Hackathon demo script

## 0:00–0:25 — The problem
"AI coding agents can write code fast. Proving it actually works, and that the safety rules hold, is still hard. KlikBeres + Kane closes that loop."

## 0:25–1:40 — Ships
Live demo: create task → plan → approve → local form → evidence with External submission: NO.

## 1:40–2:30 — Verified
Show Kane CLI run and the real browser evidence / NDJSON / exit code 0.

## 2:30–3:20 — Closed loop
Explain: Kane fails → agent reads NDJSON → writes regression test → fixes → re-runs Kane.

## 3:20–4:00 — Craft
Show UI, EN/ID toggle, zero dependencies, safety boundary.

## 4:00–4:30 — Close
"The agent plans. You approve. Kane verifies. You stay in control."
