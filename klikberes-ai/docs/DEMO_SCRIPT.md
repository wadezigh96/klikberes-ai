# 3–5 minute hackathon demo script

## 0:00–0:30 — The problem
"AI tools can explain what to do. KlikBeres is built to help people get tasks done without giving up control."

## 0:30–1:20 — Product flow
Enter a registration task, build the five-step plan, and explain the approval gate.

## 1:20–2:00 — Human control
Approve the plan. Show that the execution control only appears after approval. Run the local demo form.

## 2:00–2:40 — Evidence
Show Completed, Verified evidence, sample data, and External submission: NO.

## 2:40–3:40 — Kane CLI
Show the Kane command, real browser actions, NDJSON output, and exit code. Do not use a fabricated recording.

## 3:40–4:30 — Closed loop
If a real bug was caught, show the original failing evidence, the regression test, the fix, and the passing Kane rerun. If no bug was caught, do not stage a false claim; explain the verified checks.

## 4:30–5:00 — Close
"KlikBeres: useful automation, visible evidence, and the user stays in control."
